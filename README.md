# Medical-AI-Journey (医学影像AI实战)

这是一个基于 PyTorch 的医学影像深度学习项目，主要实现了对胸部 X 光片（Chest X-Ray）是否患有肺炎的二分类任务。

## 🛠️ 技术栈
- **编程语言**: Python 3.10
- **深度学习框架**: PyTorch, Torchvision
- **图像处理库**: OpenCV, PIL
- **环境管理**: Anaconda

## 🚀 核心功能与实现
1. **数据预处理 (Data Preprocessing)**: 将原始大尺寸 X 光片统一缩放至 224x224，并转换为单通道灰度图，最后进行归一化处理。
2. **数据加载 (DataLoader)**: 使用 `ImageFolder` 和 `DataLoader` 构建自动化数据流水线，解决数据类别不平衡问题（通过随机抽样）。
3. **模型搭建 (CNN)**: 手写了一个包含两层卷积层（Conv2d）、池化层（MaxPool2d）和两层全连接层（Linear）的卷积神经网络。
4. **模型训练 (Training Loop)**: 实现了标准的“前向传播-计算损失-反向传播-优化参数”闭环，并使用 Adam 优化器动态调整学习率。
5. **模型评估与持久化 (Evaluation & Save/Load)**: 在测试集上验证模型泛化能力，并通过 `.pth` 文件保存和加载模型权重。

## 📈 实验结果
- 在 5 个 Epoch 的小样本训练下，模型在 624 张独立测试集上的最终准确率达到了 **79.65%**。
